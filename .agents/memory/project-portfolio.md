---
name: Project portfolio boundaries
description: Organizational hierarchy is separate from activity-source links and never changes progress or permissions.
---

Portfolio parent/child relationships are organizational only, limited to two levels with one optional category per project. Existing projects must not be classified or linked automatically.

**Why:** The user approved grouping and categories for navigating the portfolio, not a new ownership model or consolidated progress methodology. Activity-source synchronization already represents a different relationship.

**How to apply:** Never infer portfolio relationships from names or source links, aggregate child progress into a parent, or inherit access through the tree. A child remains usable when its parent is inaccessible, without exposing that parent's identity. Preserve each project's independent schedule, reports and membership.
