---
name: Shared application footer
description: User-approved footer appearance should remain consistent across internal system pages.
---

Use the same footer across the system's internal pages, not a projects-only footer.

**Why:** The user liked the projects footer and explicitly requested “اعجبني اضفه في كل صفحة”.

**How to apply:** Preserve its system name/developer-credit appearance, comfortable space after content and placement at the bottom of short pages. Avoid duplicate footers. Internal application branding is not an instruction to change exported owner-facing reports.
