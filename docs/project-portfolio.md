# محفظة المشاريع

## حدود التنظيم
- التبعية تنظيمية بمستويين فقط، ولا تنقل الأعمال أو الصلاحيات أو حسابات الإنجاز.
- جميع المشاريع القديمة تبقى مستقلة وغير مصنفة حتى ينظمها المستخدم.
- الرئيسي يعرض إنجازه الأصلي، وليس متوسط التوابع.
- مدير النظام يدير الشجرة والكتالوج والإنشاء والحذف. مدير المشروع يستطيع تعديل مشروعه وإسناد تصنيف موجود فقط.
- القائمة والتصنيفات والمؤشرات مشتقة من المشاريع المسموح بها. لا تكشف القائمة أو التفاصيل معرف الرئيسي غير المتاح. لا يكتسب أحد صلاحيات بالوراثة.

## قاعدة التطوير
الترحيل الإضافي المحدود `lib/db/migrations/0010_project_portfolio.sql` يضيف الكتالوج والحقول والفهارس والحارس. لا يُشغّل تلقائياً عند بدء الخادم، ولا يستبدل قاعدة البيانات، ولا يعيد تنظيم مشاريع المستخدم.

حارس PostgreSQL والقفل المشترك يمنعان الدورات وتجاوز مستويين وحذف رئيسي له توابع، بما يشمل الكتابة المباشرة المتزامنة. تستخدم مسارات API القفل قبل الكتابة لتوحيد ترتيب الأقفال.

## النسخ الاحتياطية
- تصدير JSON الحالي يحتوي `projectCategories` وحقول التبعية والتصنيف في كل مشروع.
- مسار النسخ الكامل الموجود `scripts/dev-db-backup.mjs` يستخدم `pg_dump/pg_restore`؛ يشمل الكتالوج والحقول والقيود والحارس تلقائياً. لم يتغير مسار استعادة المستخدم ولم تُنفّذ استعادة على بياناته.
- النظام الحالي لا يملك API عاماً لاستيراد JSON. لا تضف استعادة شاملة كجزء من هذه الميزة. المساعد المحدود `restorePortfolioSnapshot` يستعيد الجزء التنظيمي فقط داخل transaction الاستيراد، بعد إنشاء المشاريع وتوفير خريطة معرّفاتها؛ يتحقق من كل المراجع والدورات قبل الكتابة، ثم يفصل العلاقات المستوردة ويعيد الجذور ثم الفروع.
- JSON القديم بلا الحقول الجديدة مقبول ويعطي مشاريع مستقلة وغير مصنفة. بعد استعادة **قاعدة كاملة** أقدم من الميزة إلى بيئة تطوير معزولة، يُطبّق الترحيل الإضافي قبل تشغيل إصدار الخادم الجديد.
- اختبارات الاستعادة تستخدم قاعدة PostgreSQL خاصة مؤقتة، لا قاعدة التطوير الحقيقية ولا الإنتاج.

## التحقق
```
NODE_ENV=development LOG_LEVEL=silent node --import ./scripts/node_modules/tsx/dist/loader.mjs --test tests/project-portfolio.integration.test.mjs
node --experimental-strip-types --test artifacts/construction-supervision/src/lib/project-portfolio.test.ts
node scripts/browser-project-portfolio.mjs
```
اختبار المتصفح يتطلب Chromium مع debugging port 9222 وخادم الويب على 22349. كل طلبات API فيه معزولة ببيانات اختبار؛ اختبارات HTTP وقاعدة البيانات الأخرى تتحقق من الخادم الحقيقي في قاعدة مؤقتة.
