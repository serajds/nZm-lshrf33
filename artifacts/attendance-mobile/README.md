# تطبيق الحضور على Android وiOS

التطبيق جزء من منتج «إدارة الإشراف والمتابعة». يستخدم واجهات النظام الحالية لتسجيل الدخول، وعرض المشاريع، والتحقق من حالة الحضور، وإرسال صورة وموقع الجهاز عند الحضور أو الانصراف.

## تجربة التطبيق على هاتف حقيقي

1. افتح المشروع في Replit وشغّل سير العمل **artifacts/attendance-mobile: expo**.
2. ثبّت تطبيق **Expo Go** من متجر الجهاز.
3. من معاينة Replit افتح رمز QR الخاص بتطبيق الجوال وامسحه:
   - Android: افتح الرابط الناتج في Expo Go.
   - iPhone: امسح الرمز بكاميرا الهاتف ثم افتحه في Expo Go.
4. سجّل الدخول برقم الهاتف وكلمة المرور المستخدمين في النظام.
5. اختر مشروعاً، واسمح للكاميرا والموقع عند ظهور رسالة النظام، ثم جرّب الحضور والانصراف.

للتسجيل يحتاج الهاتف إلى اتصال بالإنترنت؛ لا تُحفظ طلبات الحضور دون اتصال. عند فشل الطلب، أعد الاتصال واضغط «إعادة المحاولة» أو اسحب قائمة المشاريع للتحديث.

## متطلبات الأذونات والبيانات

- تطلب الكاميرا عند بدء التقاط السيلفي، ويستخدم التطبيق الكاميرا الأمامية.
- يطلب الموقع أثناء الاستخدام بعد التقاط الصورة، وليس في الخلفية.
- تُضغط الصورة قبل الإرسال وترسل بصيغة JSON نصية متوافقة مع API الحالي. يظل قرار الصلاحية والنطاق الجغرافي للخادم.
- تُحفظ بيانات الجلسة في التخزين الآمن للنظام على الهاتف. تخزين معاينة المتصفح مؤقت للجلسة فقط، وهو مخصص للتطوير لا للاستخدام كنسخة جوال.

## إعداد عنوان API للبناء المستقل

يستخدم تشغيل Replit نطاق التطوير تلقائياً. عند إعداد بيئة بناء مستقلة، عيّن `EXPO_PUBLIC_DOMAIN` إلى اسم نطاق التطبيق الذي يوجّه `/api` إلى خادم النظام. يمكن بدلاً منه ضبط `EXPO_PUBLIC_API_URL` إلى عنوان API كاملاً ينتهي بـ`/api`. لا تضع رمز دخول أو كلمة مرور في هذه القيم.

## البناء والتوزيع

إعدادات الحزمة الأصلية وأذونات Android وiOS ثابتة في `app.json`. يستخدم هذا المشروع معاينة Expo في Replit، ولا يحتاج تطبيقات Expo Go إلى ملف EAS منفصل. خطوات QR أعلاه تشغّل التطبيق داخل Expo Go ولا تنتج ملف APK أو IPA مستقلاً. لم يُضف إعداد EAS أو بناء أصلي لهذه المهمة؛ إنشاء نسخة توزيع موقعة يتطلب مسار بناء وتوقيع معتمداً وحساب Apple Developer لنسخ iOS. النشر في المتاجر خارج نطاق الإصدار الحالي.

يجب تنفيذ التحقق النهائي من الكاميرا والموقع والحضور والانصراف على هاتف Android وهاتف iPhone فعليين؛ معاينة Replit وحدها لا تثبت عمل أذونات الأجهزة أو التوقيع.
